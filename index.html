Getting Started with Whisper

Create a new private chat

  • Your connection code is generated automatically at the top.
  • Share this code with your friend.
  • Your friend pastes the code and taps Connect Privately to join.

Join an existing chat

  • Ask your friend for their connection code.
  • Paste the code into Paste friends’ connection code.
  • Tap Connect Privately to enter the chat.

Optional privacy controls

  • Swiss Protection: Enhanced privacy powered by Switzerland’s strong data protection standards.
  • Hide IP Address: keeps your network identity hidden.
  • Auto-delete on leave: removes all messages when you exit the chat.
